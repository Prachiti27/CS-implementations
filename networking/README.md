
<h1 align="center">Computer Networks</h1>

<p>
This folder contains educational implementations of fundamental
computer networking concepts related to data transmission,
communication protocols, and error detection and correction.
</p>

<p>
The implementations explore how information is transferred
between communicating systems, how transmission errors are
handled, and how protocols coordinate reliable data delivery
over communication channels.
</p>
