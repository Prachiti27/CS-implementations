<hr>

<h2>About</h2>

<p>
This repository contains implementations of fundamental Computer Science
concepts written from scratch in C++. The goal is to understand how commonly
used data structures, algorithms, and system concepts work internally rather
than treating them as black boxes.
</p>

<p>
Each topic is organized into its own folder containing the corresponding
implementations along with notes covering the core concepts, working principles,
and complexity analysis.
</p>

<h2>Goals</h2>

<ul>
  <li>Understand how fundamental CS concepts work internally.</li>
  <li>Implement algorithms and data structures from scratch.</li>
  <li>Analyze time and space complexity.</li>
  <li>Build a personal reference for CS revision.</li>
  <li>Strengthen understanding of concepts used in DSA, systems, and interviews.</li>
</ul>
