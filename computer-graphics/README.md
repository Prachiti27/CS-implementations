
<h1 align="center">Computer Graphics</h1>

<p>
This folder contains implementations of fundamental computer
graphics concepts used to represent, transform, and render
geometric objects in two-dimensional and graphical spaces.
</p>

<p>
The implementations explore geometric transformations,
rasterization, coordinate systems, and the mathematical
principles underlying the conversion of geometric descriptions
into visual representations.
</p>
