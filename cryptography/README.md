
<h1 align="center">Cryptography</h1>

<p>
This folder contains educational implementations of fundamental
cryptographic concepts used to protect information and enable
secure communication.
</p>

<p>
The implementations explore encryption, decryption, key
management, mathematical foundations of cryptography, and
the principles behind cryptographic protocols.
</p>

<p>
These implementations are intended for learning and experimentation,
not for protecting real-world sensitive information.
</p>
